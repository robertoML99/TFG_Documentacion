El objetivo principal es la construcción de un sistema de detección de intrusiones basado en técnicas de aprendizaje automático. Para ello se plantean una serie de objetivos específicos:

\begin{itemize}
\item {\normalsize \textbf{Obtener un conjunto de datos ya construido que pueda servir de base experimental.} Este debe contener el tráfico de red etiquetado y con características asociadas a sus muestras para poder entrenar y evaluar el modelo.}

\item {\normalsize \textbf{Enriquecer el conjunto de datos de partida para lograr un mayor rendimiento del IDS.} Cuando se escoja un conjunto de datos se buscará añadir información adicional que se considere relevante para enriquecer el conjunto de datos.}

\item {\normalsize \textbf{Entrenar un modelo de clasificación de aprendizaje automático para detectar y distinguir distintos tipos de tráfico.} Esto se hace con el propósito de que el modelo pueda diferenciar el tráfico benigno de los distintos tipos de ataques contenidos en el conjunto de datos.}

\item {\normalsize \textbf{Evaluar el rendimiento del modelo.} Realizando esta evaluación se podrán establecer las limitaciones del modelo y su capacidad de clasificar las muestras correctamente.}

\end{itemize}
