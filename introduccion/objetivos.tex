El objetivo principal es la construcción de un sistema de detección de intrusiones basado en técnicas de aprendizaje automático. Para ello se plantean una serie de objetivos específicos:

\begin{itemize}
\item {\normalsize Obtener un conjunto de datos ya construido que pueda servir de base experimental.}

\item Enriquecer el conjunto de datos de partida para lograr un mayor rendimiento del IDS.

\item Entrenar un modelo de clasificación de aprendizaje automático para detectar y distinguir distintos tipos de tráfico.

\item Evaluar el rendimiento del modelo.

\end{itemize}
